# JEMBEE PLAY — Mobile Menu and Separate Earnings Repair

Date: 2026-11-14
Source: `JEMBEE_PLAY_MAIN_2026-11-14.zip` (main branch archive supplied in this conversation)

## Changes

- Added a working mobile slide-out navigation drawer to the Home page's hamburger button. The drawer includes Discover navigation and separate earnings destinations.
- Added separate Sharer and Creator earnings pages. Both show confirmed Monetag USD records filtered by the authenticated user's role, and paid-video INR ledger entries in a separate section. Paid-video refunds/reversals remain signed ledger entries and are included in the INR net amount.
- Preserved `/videos/share` as a backwards-compatible route to the Sharer earnings page.
- Added a read-only authenticated paid-video earnings API. It scopes `shortsSettlementLedger` reads to the signed-in user's `beneficiaryUid`, then separates `creator_share`/`creator_share_reversal` from `sharer_share`/`sharer_share_reversal`.
- Added a read-only authenticated Teacher Referral Commission API and page. The API scopes ledger reads to the signed-in user's `beneficiaryUid`, not `teacherUid`.

## Important accounting clarification from existing source

The existing teacher-referral reconciliation route assigns the 2% commission to the verified `referrerUid` (stored as `beneficiaryUid`). `teacherUid` identifies the referred teacher. Therefore the separate menu item is named **Teacher Referral Commission**: it is the referrer's commission generated by the referred teacher's eligible paid-video activity, not the teacher's own Creator earnings. A teacher's own Creator earnings are shown on the Creator page.

Teacher commission is calculated only from verified, refund-adjusted Admin Net Profit. The page reads the current commission projection and displays adjustment rows separately; it does not add adjustment rows again to the current total.

## Safety boundaries

- No Firestore documents, rules, indexes, collections, payouts, wallets, or payment transfers were changed.
- No fake balances or sample earnings are generated.
- Monetag amounts remain USD; paid-video settlement amounts remain INR and are not combined.
- Pending settlement is not represented as a completed bank payout.
- Teacher referral adjustment rows are shown as audit history and are not double-counted in the current commission total.
