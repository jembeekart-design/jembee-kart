# Trust & Safety module

Phase 17 adds a pure copyright-claim contract and review-decision parser. The public submission route verifies a revoked-token-aware Firebase ID token, bounds request size, validates claimant attestations and source URL, confirms the target video exists, and creates a deterministic pending claim in a server-only Firestore collection.

Important: submission is not a finding of infringement and does not automatically hide, delete, or disable a video. Takedown/restoration actions require a separate authorized human review workflow. This phase does not claim to implement statutory notice/counter-notice compliance, identity verification, email delivery, or legal review.
