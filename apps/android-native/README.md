# JEMBEE PLAY Native Android Apps

This directory contains two independent Android application targets:
- `mobile`: touch-first Android phone/tablet application (`in.jembeeplay.mobile`)
- `tv`: Android TV / Google TV lean-back application (`in.jembeeplay.tv`)

## Build
Requires Android Studio with JDK 17, Android SDK 35 and Gradle wrapper generated/managed by Android Studio.
Open `apps/android-native` in Android Studio and sync Gradle. Build each application variant separately.

## Current foundation status
- Native Android project structure and separate application IDs are established.
- Mobile and TV have independent Compose entry points and navigation shells.
- Theme state (Light / Dark / System) is represented in each app shell.
- TV manifest advertises Leanback launcher support and touchscreen is not required.
- Screens currently use clearly marked sample presentation data. Authentication, live feed APIs, upload, paid playback, notifications, downloads, analytics and monetization are not connected in this foundation.
- No release APK/AAB is generated by this source-only commit. Signing, backend integration, automated tests and physical-device verification remain release gates.

## Security and release rules
- Never commit Firebase service-account keys, Cashfree secrets, signing keystores or passwords.
- Mobile and TV must use separate package IDs and release tracks.
- Do not enable paid checkout or payouts from the native clients. All entitlement and settlement decisions remain server-authoritative.
- Direct APK URLs must only be published after signed builds, SHA-256 checksums, malware scanning and device QA.
- Keep APK and AAB release artifacts for the same tested version; AAB is for later Play Console submission.
